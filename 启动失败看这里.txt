BabelDOC Studio 启动失败？先看这里
=============================

如果双击 Start.bat（签名版则双击 BabelDOC Studio.exe）时 Windows 弹出：

  「智能应用控制已阻止可能不安全的文件」
  「此文件已被阻止，因为来自 Internet 的此类型文件可能存在危险」

这不是安装包损坏，而是 Windows 11 的「智能应用控制」(SAC) 在拦截从网上下载的文件。
用资源管理器右键「全部解压缩」时，ZIP 的「来自 Internet」标记会复制到每个文件，脚本和未签名的程序尤其容易被拦。

补充：只要 BabelDOC Studio.exe 或 Start.bat 还能运行，它们首次运行会自动清除包内所有文件的标记，
不需要你手动输入命令；只有它们本身被拦时，才需要做下面第 1 步。

按下面顺序处理，多数情况第 1 步就能解决：

1) 清掉「来自 Internet」标记（推荐）
   打开解压后的文件夹，在空白处右键 →「在终端中打开」，粘贴并回车：

   Get-ChildItem -Recurse -File -ErrorAction SilentlyContinue | Unblock-File

   （PowerShell 里先 cd 到解压目录也可以。）然后重新双击 Start.bat。

   也可以只处理被拦的那个文件：右键 → 属性 → 勾选「解除锁定」。

2) 重新解压时换一种方式
   解压前先右键 ZIP → 属性 → 勾选「解除锁定」，再用资源管理器解压；
   或者直接在 PowerShell 里解压（不会传播 Internet 标记）：

   Expand-Archive -LiteralPath "下载的ZIP路径" -DestinationPath "解压目标目录"

   然后双击 Start.bat。

3) 如果提示变成「智能应用控制已阻止可能不安全的应用」
   说明 SAC 拦的是没有数字签名的程序（本包目前未做代码签名）。
   SAC 没有白名单，只能：
   · 关闭智能应用控制（设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 →
     智能应用控制 → 关闭；关闭会降低系统防护，旧版 Windows 关闭后要重装系统才能再开启）；
   · 或等本项目的签名版发布。

注意：
· 「更多信息 → 仍要运行」是 SmartScreen 的选项，对智能应用控制无效。
· 不要下载 GitHub 自动生成的 Source code ZIP，那里面没有运行时，无法直接启动。
