BabelDOC PDF 翻译器（中文界面）
================================

使用方法：
1. 双击桌面的“BabelDOC 翻译器”。
2. 点击“添加 PDF”，或直接把一个或多个 PDF 拖到文件列表区域。
3. 选择服务商预设，只需填写 API Key；也可以手动修改 API 地址和模型。
4. 选择输出目录，点击“开始翻译”。

说明：
- 默认源语言为英文（en），目标语言为中文（zh）。
- 可勾选“保存（Windows 加密）”。密钥将由 Windows DPAPI 加密，只有当前 Windows 用户可以解密。
- 内置 OpenAI、DeepSeek、阿里云百炼（Qwen）、智谱 GLM、OpenRouter 和自定义预设。
- 首次翻译可能需要下载字体和版面分析资源，因此会比以后慢。
- 如果资源下载超时，可以稍后重试。
- 默认同时生成纯译文 PDF 和中英双语 PDF。
- 翻译完成后自动重命名为“原文件名_译文.pdf”和“原文件名_双语对照.pdf”。
- 如果目标名称已经存在，会自动追加“(2)”“(3)”等序号，不覆盖旧文件。

项目主页：https://github.com/funstory-ai/BabelDOC
