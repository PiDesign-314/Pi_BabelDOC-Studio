BabelDOC PDF 翻译器（中文界面）
================================

使用方法：
1. 双击桌面的“BabelDOC 翻译器”。
2. 把 PDF 拖进窗口中央的上传区域（也可以直接点它选择文件）。
3. PDF 加入后点「翻译设置」里的「修改」打开设置弹窗：选择服务商预设，只需填写 API Key；
   也可以手动修改 API 地址和模型。免费选项包括 Google 翻译（无需 Key）、Gemini 免费额度、
   OpenRouter 免费模型和本地 Ollama。
4. 输出目录在设置弹窗下方或高级选项里调整，然后点击“开始翻译”。

说明：
- 上传前界面只有一个拖拽入口，翻译设置与“高级设置”都要等 PDF 加入后才出现。
- 移除全部文件后会自动回到上传入口，方便开始下一个任务。
- 翻译中会显示一张文件进度卡片：文件名、大小 / 页数，右侧是阶段进度条和“已用”时间；
  完成时显示结果文件，失败时保留错误信息。
- 术语库面板顶部有「预设术语库」：人工智能 · 大模型、交互设计 · 人机交互，
  首次启动会自动安装，删掉后点「添加」就能重新装回来。
- 翻译结束后点结果行的“阅读”，或打开右上角“结果库”，可以直接在应用里读译文。
  阅读时页面连续滚动，读到页尾直接接上下一页；选中的文字可以跨页，一次就能标完整段。
  选中正文即可高亮（八色：黄 / 绿 / 蓝 / 粉 / 橙 / 紫 / 青 / 红），划词时还能直接选
  荧光笔 / 蜡笔 / 手绘 / 实线划线 / 铅笔划线 / 波浪线；点“便签”可以在页面上写评论；
  带评论的划线会在行尾显示便签标志，鼠标悬停就能展开备注预览，点一下进入编辑。
  阅读器底部是一条悬浮工具坞：选择 / 移动、页面文字、便签、自由画、直线、橡皮擦，
  以及标记样式、墨色粗细、字体字号、纸面颜色（含水墨屏）、颜色标签和批注版式都在这里；
  工具坞可以在“自定义工具栏”里调整顺序和显隐。
  “页面文字”直接在页面上输入，不再弹出编辑窗口；输入时底部会出现格式条，
  可以改颜色、字体（支持本机字体和导入的 .ttf / .otf / .ttc 手写体）和字号，
  写下的说明可以拖动位置，空白文字结束编辑时会自动移除。
  侧栏可拖动右边缘调宽；顶部色点可按颜色筛选批注；
  “批注显示”可以在“页面内 / 页边距”之间切换，页边距模式把备注排到页面右侧。
  批注会自动保存，也可以在侧栏统一查看、跳转、删除。
  点侧栏里的某条批注，会直接跳到文字所在的位置并闪一下提示。
  读“双语对照”时，在哪一侧划词，另一侧同一段落的文字会同步亮起（拖动时实时跟随，
  点空白处消失），方便对照着看原文和译文。
  左侧「目录」页签会自动识别论文结构：有书签用书签，没有就按字号和编号识别标题；
  点条目跳到对应页并高亮标题，滚动时当前章节会自动高亮，也可以输入关键字过滤。
  选中正文后点右键「引用提问…」，选中的句子会带进右侧「AI 助读」面板；直接问
  “这个结论有实验支撑吗？”，回答里的每个论断后面都有 p.N 出处，点一下就能回到原文
  并闪烁高亮，回答末尾还有“依据”列表。默认使用本机已登录的 Codex / Kimi / Claude CLI，
  不需要 API Key；也可以在面板的「模型设置」里改填其他 OpenAI 兼容接口的地址、模型和 Key。
  滚轮上下阅读，Ctrl + 滚轮缩放，← / → 整页跳转，Home / End 到首尾页。
  关掉再打开同一篇时，会自动回到上次读到的那一页。
- 右上角“导出”里有两个选项：
  · 导出 Markdown：把全部批注按页码导出成 .md，方便粘到笔记软件；
  · 保存带批注的 PDF：在原 PDF 旁边生成“原文件名_批注.pdf”，
    高亮、划线、便签和文字会写成标准 PDF 注释，用 Edge / Acrobat / 预览打开都能看到。
    这份 PDF 可以直接发给别人；对方在应用里打开它时，阅读器会自动读回里面的批注。
- “结果库”会把同一篇论文的译文 / 双语对照 / 术语表放在一张卡片里：可以搜索、
  按时间或名称排序、整套重命名、移入回收站；“添加文件夹”可以把别处的结果也纳入管理。
- 如果更新程序后没有重启应用，阅读器顶部会出现「重启应用」提示条，点一下即可重启；
  新批注需要新版后端才能写入磁盘。
- 结果库左侧可以建“合集”，按课题把论文分组：
  点「＋」新建合集 → 回到全部结果，点卡片上的“归类”勾选合集；
  点左侧合集只显示其中的论文，“未分类”显示还没归类的；
  合集可重命名或删除（只解除归类，不删论文文件）；论文改名后仍留在原合集里。
- 默认源语言为英文（en），目标语言为中文（zh）。
- 可勾选“保存（Windows 加密）”。密钥将由 Windows DPAPI 加密，只有当前 Windows 用户可以解密。
- 内置 OpenAI、DeepSeek、阿里云百炼（Qwen）、智谱 GLM、OpenRouter 和自定义预设。
- 首次翻译可能需要下载字体和版面分析资源，因此会比以后慢。
- 如果资源下载超时，可以稍后重试。
- 默认同时生成纯译文 PDF 和中英双语 PDF。
- 翻译完成后自动重命名为“原文件名_译文.pdf”和“原文件名_双语对照.pdf”。
- 同一篇论文的所有产物会自动收进输出目录下以论文名命名的子文件夹，
  例如“输出目录\论文名\论文名_译文.pdf”，方便按论文管理。
- 如果目标名称已经存在，会自动追加“(2)”“(3)”等序号，不覆盖旧文件。
- 在“结果库”里重命名论文，对应的子文件夹会一起改名；删除论文时文件夹会一并清理。
